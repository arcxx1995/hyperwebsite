# Hyperspark

## Design Context

Marketing site for **Hyperspark** — a Building with AI school. Register: **brand**. Primary goal: conversion (sign up / enroll).

Full strategic context in `PRODUCT.md`. Full visual spec in `DESIGN.md` (currently a seed — re-run `/impeccable document` once code exists).

**Quick reference:**
- Personality: bold, urgent, energetic — through precision, not volume
- Theme: dark-mode native (near-black canvas, committed electric violet)
- Type: monospace display + geometric sans body
- Motion: choreographed — stagger entrances, every animation has reduced-motion fallback
- References: Vercel.com, Raycast.com
- Anti-references: corporate learning platforms (Workday/SAP), generic AI-startup aesthetic (gradients/glows/buzzwords), bootcamp high-pressure tactics

**Hard prohibitions:** glassmorphism, gradient text, neon glow, `border-left` stripe accents, pill buttons, walls of text, fake urgency (countdown timers, testimonial spam).
